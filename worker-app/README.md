# Sanitrax Worker App

Isolated React application for maintenance workers in the Sanitrax Smart Toilet Monitoring System.

## Module Isolation
This app is designed to run independently from the main Sanitrax web frontend.

## Planned Features
- Worker Authentication & Session Management
- Worker Dashboard (Assigned, Pending, In-progress, Solved complaints)
- Complaint Details & Navigation
- Complaint Resolution & Image Uploads
- Admin Assignment Notifications

## Development
```bash
npm install
npm start
```
